# The Beyond the Basics prompt

Beyond the Basics is the next level after the learning guide. It is for a
reader who has finished the learning guide, or has the same experience, and
whose projects now need more than the basics. It starts from the "Beyond the
basics" roadmap at the end of the learning guide.

Input: a finished `<subject>-learning-guide.pdf`.
Output: `<subject>-beyond-the-basics-learning-guide.pdf`, saved in the same
subject folder.

## What a finished Beyond the Basics guide contains

Taken from the existing guide (CMake):

- The same format as the learning guide: "Who it is for", how long it takes,
  which version it targets, "Before you start", one idea per chapter, and
  one project that grows chapter by chapter.
- "Who it is for" names the learning guide as the prerequisite.
- One mental model, stated at the start and repeated in each chapter.
